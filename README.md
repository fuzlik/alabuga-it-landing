# Алабуга IT — лендинг

Пиксель-в-пиксель вёрстка по [Figma Landing-IT](https://www.figma.com/design/Z7XB4lxQIgCXRghWYEANFd/Landing-IT?node-id=417-103).

Сайт: https://fuzlik.github.io/alabuga-it-landing/

## Запуск

```bash
npm install
npm run dev
```

## Версии

| | Размер | Breakpoint |
|---|---|---|
| Desktop | 1920×13994 | ≥ 768px |
| Mobile | 390×11064 | < 768px |

Макет масштабируется под ширину окна.

## Шрифты

- **Bounded** — `public/fonts` (SIL OFL)
- **Muller** → Montserrat (Google Fonts)
- **Source Code Pro**, **Roboto Flex** — Google Fonts
